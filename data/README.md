# Curated SFT Data

This directory is for manually curated and teacher-generated chat/SFT data that is specific to this fork.

Current planned use:

- `manual_reasoning_chat_v1.jsonl`
  - high-signal reasoning/chat conversations
  - used by the `reasoning_manual_v1` preset in `scripts/chat_sft.py`

- `manual_reasoning_chat_v2.jsonl`
  - broader manually curated reasoning/chat conversations with more MMLU-style coverage
  - generated by `build_manual_reasoning_v2.py`
  - used by the `reasoning_manual_v2` preset in `scripts/chat_sft.py`

- `teacher_reasoning_v1.jsonl`
  - first teacher-generated reasoning/chat candidate built from public synthetic sources
  - generated by `build_teacher_reasoning_v1.py`
  - initial composition is `Magpie-Ultra` + `Orca-Math` with deterministic sampling and a metadata manifest
  - kept as the original teacher pool; not the current launch target

- `teacher_reasoning_v1b.jsonl`
  - rebalanced teacher-generated reasoning/chat set for the first trainable teacher branch
  - generated by `build_teacher_reasoning_v1.py` with explicit source quotas
  - current composition is `400` Magpie-Ultra rows + `200` Orca-Math rows
  - used by the `teacher_reasoning_v1b` preset in `scripts/chat_sft.py`

- `teacher_reasoning_v2.jsonl`
  - selected teacher-generated reasoning/chat set built from `OpenThoughts-114k`, `OpenR1-Math-220k`, and filtered `Magpie-Ultra`
  - generated by `build_teacher_reasoning_v2.py`
  - current composition is `220` OpenThoughts + `180` OpenR1 + `120` Magpie rows
  - used by the `teacher_reasoning_v2` preset in `scripts/chat_sft.py`

JSONL schema:

- one conversation per line
- each line is a JSON array
- roles must alternate starting with `user`
- each message must contain:
  - `role`
  - `content`

Example:

```json
[{"role":"user","content":"What is 12 * 13?"},{"role":"assistant","content":"12 * 13 = 156."}]
```

Curation rules:

- keep examples short and high-value
- prefer reasoning, grounded QA, concise math, and disciplined refusals
- avoid filler chat
- avoid identity/personality stuffing in the generalist branch
- keep spelling/letter-count specialist data out of this file

Operational rules:

- do not launch `reasoning_manual_v1` from the starter scaffold alone
- the automation wrapper enforces a minimum row count before training
- `reasoning_manual_v2` expects at least `200` rows and is intended for fixed-geometry `s768` replications
- `teacher_reasoning_v1b` is retained as the failed first teacher-data branch
- `teacher_reasoning_v2` is the current selected teacher-data training target and is wired into a fixed-`s768`, deterministic, 2-seed gated run
